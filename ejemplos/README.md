# Archivos de prueba

Cada archivo sigue el formato del enunciado (`"algoritmo": "reemplazo-equipos"`).

| Archivo | Qué prueba |
|---|---|
| `reemplazo-equipos-01-enunciado.json` | Ejemplo del enunciado (costo mínimo 640, 3 planes óptimos) |
| `reemplazo-equipos-02-carro-5-anios.json` | Ejercicio clásico de libro de texto (costo mínimo 31 000) |
| `reemplazo-equipos-03-vida-1-anio.json` | Vida útil de 1 año: se reemplaza cada año |
| `reemplazo-equipos-04-vida-mayor-que-plazo.json` | Vida útil mayor que el plazo |
| `reemplazo-equipos-05-decimales.json` | Montos con decimales |
| `reemplazo-equipos-06-empates-multiples.json` | Muchos planes óptimos empatados |
| `reemplazo-equipos-07-maximo-30-anios.json` | Caso máximo (plazo 30, vida útil 10) |
| `reemplazo-equipos-08-reventa-cero.json` | Reventa nula |

La carpeta `invalidos/` tiene archivos que deben mostrar un mensaje claro al cargarlos (nunca un error).
